## Purpose

面向学生的关怀式对话，识别学习压力下的情绪状态并给出共情回应。这条通道与学科助手分离，不做学业判断，也不做心理诊断——它的作用是让学生被听见，并在出现高风险表达时引导其寻求真实的人的帮助。

## ADDED Requirements

### Requirement: 情绪识别与共情回应

系统 SHALL 接受学生的自由文本输入，识别其情绪倾向，并返回对应的共情回应与识别出的情绪标签。

当输入不匹配任何已知情绪特征时，系统 MUST 返回中性的开放式回应，而非强行归类到某一情绪。

#### Scenario: 表达焦虑
- **WHEN** 学生输入中含有焦虑、紧张、压力类表达
- **THEN** 系统返回情绪标签为焦虑
- **AND** 回应内容为共情与可执行的缓解建议

#### Scenario: 表达积极
- **WHEN** 学生输入中含有感谢、开心、有进展类表达
- **THEN** 系统返回情绪标签为积极
- **AND** 回应内容为肯定与继续推进的邀请

#### Scenario: 无明确情绪特征
- **WHEN** 学生输入不匹配任何已知情绪特征
- **THEN** 系统返回中性情绪标签
- **AND** 回应为开放式邀请，不做情绪归类

### Requirement: 高风险表达触发求助引导

当输入中出现表征强烈无助或崩溃的表达时，系统 MUST 在共情回应之外附加求助引导，提示学生不要独自承受并寻求可信赖的人或专业帮助。

该引导文案 MUST 为固定内容，MUST NOT 由生成过程自由发挥。

#### Scenario: 出现高风险表达
- **WHEN** 学生输入中包含表征强烈无助或崩溃的表达
- **THEN** 回应中包含共情内容
- **AND** 回应中附加固定的求助引导文案

#### Scenario: 普通负面情绪不触发
- **WHEN** 学生表达一般性的沮丧或疲惫，未达高风险特征
- **THEN** 回应为共情内容
- **AND** 不附加求助引导文案

### Requirement: 不做诊断、不用于评价

系统 MUST NOT 输出任何形式的心理健康诊断或病理判断。

情绪识别结果 MUST NOT 出现在学情分析、教师端统计或任何面向教师的界面中。

#### Scenario: 情绪数据不外泄到教师端
- **WHEN** 教师请求班级统计或任一学生的学情分析
- **THEN** 响应中不包含任何关怀对话的内容或情绪标签

#### Scenario: 回应不含诊断表述
- **WHEN** 学生的任何输入被处理
- **THEN** 回应中不包含疾病名称、诊断结论或治疗建议

### Requirement: 关怀对话的可见性限于本人

若关怀对话被持久化，其内容 MUST 仅对该学生本人可读。

#### Scenario: 他人尝试读取
- **WHEN** 任何其他用户（含教师）尝试读取某学生的关怀对话
- **THEN** 系统返回 404 或 403，不返回内容
