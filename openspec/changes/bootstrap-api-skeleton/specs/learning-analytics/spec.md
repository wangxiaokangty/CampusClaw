## Purpose

由学生的提问、作业与错题实时计算出的学情视图：学生端看到自己的知识点掌握雷达、成绩趋势与 AI 学习画像，教师端看到班级整体的掌握分布与活跃度。这些是计算结果而非存储数据，随底层行为数据变化而变化。

## ADDED Requirements

### Requirement: 学生个人学情

系统 SHALL 提供端点返回当前学生的学情数据，包含：各学科掌握度、近期成绩趋势序列、综合得分、统计摘要（提问次数、提交份数、正确率、错题数），以及学习画像（学习风格、优势知识点、待提升知识点、学习建议、标签）。

学科维度 MUST 覆盖该学生所在班级已开设的全部学科。

#### Scenario: 读取个人学情
- **WHEN** 学生请求自己的学情分析
- **THEN** 系统返回掌握度、趋势、综合得分、统计摘要与学习画像
- **AND** 学科维度与本班已开设学科一致

#### Scenario: 错题影响掌握度
- **WHEN** 学生在某学科存在错题
- **THEN** 该学科的掌握度低于无错题时的取值

#### Scenario: 读取他人学情
- **WHEN** 学生请求其他学生的学情分析
- **THEN** 系统返回 403 或仅返回自己的数据

### Requirement: 统计摘要取真实值

统计摘要中的提交份数、正确率与错题数 MUST 由该学生的真实提交与错题记录计算得出，MUST NOT 使用模拟值。

正确率定义为：已批改且未判错的提交数占已批改提交总数的比例。无已批改提交时，正确率为 0。

#### Scenario: 提交后统计更新
- **WHEN** 学生新增一份提交并完成批改
- **THEN** 统计摘要中的提交份数增加
- **AND** 正确率按最新的已批改提交重新计算

#### Scenario: 无提交记录
- **WHEN** 学生尚无任何提交
- **THEN** 提交份数为 0，正确率为 0
- **AND** 端点返回成功而非错误

### Requirement: 模拟指标的显式标注

本阶段部分指标（学科掌握度基准值、成绩趋势的历史段、学习风格判定、班级活跃度序列）为确定性模拟值。这些指标 MUST 是确定性的——相同输入恒产生相同输出，MUST NOT 每次请求随机变化。

接口文档 MUST 标注哪些字段为演示数据。

#### Scenario: 重复请求结果稳定
- **WHEN** 学生在底层数据未变化的情况下连续两次请求学情分析
- **THEN** 两次返回的掌握度与趋势数值完全一致

### Requirement: 教师端班级统计

系统 SHALL 提供端点返回教师所在班级的整体统计：各学科平均掌握度、班级综合得分、近七日活跃度序列、学生人数、技能调用总次数。

技能调用总次数 MUST 取自真实的审计记录。

#### Scenario: 读取班级统计
- **WHEN** 教师请求本班统计
- **THEN** 系统返回学科掌握分布、综合得分、活跃度序列、学生人数与技能调用次数

#### Scenario: 学生尝试读取班级统计
- **WHEN** 学生请求班级统计端点
- **THEN** 系统返回 403

#### Scenario: 统计不跨班
- **WHEN** 教师请求本班统计
- **THEN** 学生人数与技能调用次数仅统计本班，不含其他班级
