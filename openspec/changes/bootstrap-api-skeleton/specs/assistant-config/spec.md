## Purpose

管理每个班级下各学科助手的行为配置：系统提示词、AI 技能的启停与增删、外部工具服务器（MCP）的连接。教师可配置，学生只读——这条不对称是产品的核心约束之一，学生不得改变助手的行为规则。

## ADDED Requirements

### Requirement: 助手列表与详情

系统 SHALL 提供端点返回请求者所属班级的学科助手，每个助手含学科、图标、名称、系统提示词、绑定的讲义标识列表、技能列表与 MCP 服务器列表。

响应 MUST NOT 包含 API Key 明文。若需展示，MUST 以打码形式返回（保留首尾少量字符）。

#### Scenario: 教师查看助手配置
- **WHEN** 教师请求本班某学科助手
- **THEN** 系统返回该助手的完整配置
- **AND** API Key 字段为打码形式或缺失，不含明文

#### Scenario: 学生查看助手配置
- **WHEN** 学生请求本班某学科助手
- **THEN** 系统返回同样的配置内容
- **AND** API Key 字段为打码形式或缺失，不含明文

### Requirement: 教师编辑提示词与绑定讲义

教师 SHALL 能修改助手的系统提示词，以及该助手检索时所绑定的讲义范围。

绑定的讲义 MUST 属于同一班级且同一学科，否则拒绝。

#### Scenario: 修改提示词
- **WHEN** 教师提交新的系统提示词
- **THEN** 系统保存该提示词
- **AND** 后续对话使用新提示词

#### Scenario: 绑定跨学科讲义
- **WHEN** 教师尝试为数学助手绑定一份语文讲义
- **THEN** 系统返回 400
- **AND** 绑定关系保持不变

### Requirement: AI 技能的启用与停用

每个助手持有若干 AI 技能，每个技能含名称、触发时机描述、行为描述、启用状态、是否内置必需，以及绑定的工具列表。

教师 SHALL 能切换技能的启用状态。内置必需技能 MUST NOT 被删除，但 SHALL 可以被停用。

#### Scenario: 停用技能
- **WHEN** 教师停用「解题引导」技能
- **THEN** 该技能的启用状态变为停用
- **AND** 后续对话不再路由到该技能

#### Scenario: 删除内置必需技能
- **WHEN** 教师尝试删除标记为内置必需的技能
- **THEN** 系统返回 400
- **AND** 技能保持存在

### Requirement: 自定义技能的新增与删除

教师 SHALL 能新增自定义技能，指定名称、触发时机、行为描述与绑定工具。绑定的工具 MUST 来自内置工具或该助手已连接的 MCP 服务器所暴露的工具。

教师 SHALL 能删除自定义技能。

#### Scenario: 新增自定义技能
- **WHEN** 教师提交一个新技能，其绑定工具均来自已连接的服务器
- **THEN** 系统创建该技能并返回其标识
- **AND** 该技能出现在助手的技能列表中

#### Scenario: 绑定不存在的工具
- **WHEN** 教师提交的技能绑定了一个未连接服务器的工具
- **THEN** 系统返回 400 并指出无效的工具
- **AND** 不创建技能

### Requirement: 从技能包导入技能

教师 SHALL 能上传 .zip 技能包导入技能。系统 MUST 解析包内的清单文件以获取技能的名称、触发时机、行为与工具。

若压缩包无法解析，系统 MUST 返回错误而非创建空技能。若压缩包有效但缺少清单文件，系统 MUST 返回可解析的部分并标注需要人工补全，而非直接失败。

#### Scenario: 导入含清单的技能包
- **WHEN** 教师上传一个含有效清单文件的 .zip
- **THEN** 系统从清单解析出技能字段并返回供确认
- **AND** 标注清单已成功解析

#### Scenario: 导入缺少清单的技能包
- **WHEN** 教师上传一个有效的 .zip 但其中无清单文件
- **THEN** 系统返回可识别的内容并标注「未找到清单，需手动补全」
- **AND** 不自动创建技能

#### Scenario: 上传非 zip 文件
- **WHEN** 教师上传的文件不是有效的 .zip
- **THEN** 系统返回 400 并提示需要 .zip 格式

### Requirement: MCP 服务器连接与工具发现

教师 SHALL 能为助手添加 MCP 服务器，提供名称与地址。系统 MUST 执行一次连接握手并返回该服务器暴露的工具列表，连接成功后服务器状态标记为已连接。

本阶段握手为模拟行为，不发起真实的 MCP 协议通信；此限制 MUST 在接口文档中标注。

内置的知识库检索服务器 MUST NOT 被删除。

#### Scenario: 添加 MCP 服务器
- **WHEN** 教师提交服务器名称与地址
- **THEN** 系统返回该服务器记录，状态为已连接，并附带发现到的工具列表
- **AND** 这些工具随即可被该助手的技能绑定

#### Scenario: 删除自定义 MCP 服务器
- **WHEN** 教师删除一个非内置的 MCP 服务器
- **THEN** 该服务器从助手配置中移除
- **AND** 任何绑定了其工具的技能被同步清理该工具绑定，不留悬空引用

#### Scenario: 删除内置服务器
- **WHEN** 教师尝试删除内置的知识库检索服务器
- **THEN** 系统返回 400
- **AND** 服务器保持连接

### Requirement: 学生不可修改配置

所有修改助手配置的操作——提示词、技能增删改与启停、MCP 服务器增删——MUST 拒绝学生身份的调用。

#### Scenario: 学生尝试启用技能
- **WHEN** 学生请求切换某技能的启用状态
- **THEN** 系统返回 403
- **AND** 技能状态保持不变
