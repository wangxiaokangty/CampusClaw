## Purpose

记录每一次 AI 技能调用，供教师核查助手的实际行为。审计是这个产品对「AI 在课堂里做了什么」这一问题的回答——每条技能调用都留痕，含技能标识、参数摘要、结果与开销。

## ADDED Requirements

### Requirement: 技能调用留痕

系统 MUST 为每次 AI 技能调用写入审计记录，含：时间、用户标识、用户姓名、班级标识、技能标识、动作描述、参数摘要、结果状态、耗时与 token 用量。

产生审计的场景至少包括：助手对话响应完成、作业批改完成、错题讲解生成。

参数摘要 MUST 为截断后的摘要而非完整输入，避免留存过长的学生原文。

#### Scenario: 对话产生审计
- **WHEN** 一次助手对话响应完成
- **THEN** 审计中新增一条记录，技能标识与该次路由到的技能一致

#### Scenario: 失败调用也留痕
- **WHEN** 一次技能调用执行失败
- **THEN** 审计中仍新增记录，结果状态标记为失败

#### Scenario: 参数摘要被截断
- **WHEN** 学生提交一段很长的输入触发技能调用
- **THEN** 审计记录的参数摘要为截断形式，不含完整原文

### Requirement: 教师查询审计日志

教师 SHALL 能查询本班审计日志，支持按技能标识、结果状态与用户过滤，并分页返回。结果按时间降序。

#### Scenario: 查询全部日志
- **WHEN** 教师请求审计日志且未指定过滤条件
- **THEN** 系统按时间降序分页返回本班全部记录

#### Scenario: 按技能过滤
- **WHEN** 教师指定某技能标识查询
- **THEN** 仅返回该技能的调用记录

#### Scenario: 按失败状态过滤
- **WHEN** 教师筛选结果状态为失败的记录
- **THEN** 仅返回失败的调用记录

#### Scenario: 审计不跨班
- **WHEN** 教师查询审计日志
- **THEN** 结果中不含任何其他班级的记录，无论过滤条件如何组合

### Requirement: 审计聚合统计

系统 SHALL 提供本班审计的聚合统计：总调用次数、失败率、总 token 用量，以及按技能维度的调用次数与失败次数。

失败率定义为失败记录数占总记录数的比例。无记录时失败率为 0。

#### Scenario: 读取聚合统计
- **WHEN** 教师请求审计统计
- **THEN** 系统返回总调用次数、失败率、总 token 用量与按技能的分项统计

#### Scenario: 无审计记录
- **WHEN** 本班尚无任何审计记录
- **THEN** 总次数与 token 为 0，失败率为 0
- **AND** 端点返回成功而非错误

### Requirement: 学生不可访问审计

审计查询与统计端点 MUST 拒绝学生身份的调用。

#### Scenario: 学生尝试查询审计
- **WHEN** 学生请求审计日志或审计统计
- **THEN** 系统返回 403
